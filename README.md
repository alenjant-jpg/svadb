# Алишер & Айлин — свадебное приглашение

Одностраничный сайт. **Всё внутри одного файла `index.html`** — акварели и музыка
зашиты внутрь (base64). Файл можно пересылать в мессенджере, открывать с флешки,
с любого места на диске и вообще без интернета.

```
wedding/
├─ index.html          ← сам сайт, готов к заливке (≈1,9 МБ)
├─ README.md           ← этот файл
└─ img/                ← исходники, на всякий случай
   ├─ venue.webp       Millennium
   ├─ dress.webp       дресс-код
   ├─ arch.webp        арка
   └─ chandelier.webp  люстра (отделена, чтобы качалась)
```

## Что правится за минуту

Откройте `index.html` в редакторе (Блокнот, VS Code), найдите блок `var CFG = {`
в самом низу файла:

```js
var CFG = {
  EVENT : '2026-09-21T18:00:00+05:00',   // ← ВРЕМЯ ПОКА ЗАГЛУШКА

  RSVP_MODE : 'email',                   // 'email' | 'whatsapp' | 'telegram' | 'form'
  EMAIL     : 'aylin.h.26@mail.ru',
  WHATSAPP  : '77000000000',
  TELEGRAM  : 'username',
  FORM_URL  : '',

  MAP : 'https://2gis.kz/almaty/search/Millennium'
};
```

**Обязательно поменять:**

1. **Время.** Сейчас стоит 18:00 как заглушка. Поменяйте в `EVENT` — карточка
   «Время» подтянет его сама, отдельно править не нужно.
2. **Ссылка 2ГИС.** Сейчас это поиск по слову Millennium. Лучше вставить прямую
   ссылку на карточку заведения.
3. **Почта для ответов**, если нужна другая.

## Как всё устроено

### Конверт
Первый экран — запечатанный конверт, перевязанный лентой, с настоящей сургучной
печатью: корона, литера **A** и лавровый венок. Прокрутка заблокирована,
единственный путь дальше — нажать в любом месте экрана.

Раскрытие идёт четырьмя кадрами:

1. печать **раскалывается пополам**, половинки разлетаются и падают
2. конверт **ложится в наклон**, как на стол, и клапан откидывается назад —
   внутри виден затенённый карман
3. карточка с именами **выезжает вверх из кармана**, за передней стенкой
4. конверт выпрямляется, **камера влетает в карточку**, та заполняет экран
   и растворяется — под ней сайт, музыка уже играет

### Millennium
Акварель ресторана на кремовом фоне — белый фон снимка вырезан, поэтому рисунок
лежит прямо на странице, без белого прямоугольника. Над ним ваш текст
«Мы хотим разделить с вами этот особенный день», снизу имена и дата.
Через кадр пролетает птица — машет крыльями и уходит за край.

### Дата и отсчёт
Крупное «21 сентября», живой таймер до торжества, карточки с датой, временем
и местом, кнопка в 2ГИС.

### Карусель
Две ваши фотографии и одна пустая рамка про запас. Листается пальцем вбок,
кадры вертикальные 2:3, внутри тонкая золочёная кайма. Пришлёте ещё —
вставлю, места сколько угодно.

### Дресс-код
Ваша акварель целиком, тоже без белого фона.

### Опросник в арке
Мраморная арка, **люстра отделена от неё в отдельный слой и качается** как маятник,
период 5,2 секунды, вокруг неё пульсирует тёплое свечение. Внутри арки — дата
со временем и форма «Приду / Не приду», имя и количество человек. Поля подогнаны
так, чтобы вся форма помещалась между колоннами и не наезжала на основание арки.
Ответ уходит письмом на **aylin.h.26@mail.ru** — на экране почта не показывается.

### Мелочи
- по странице летают две бабочки, крылья машут
- королевские вензеля по углам, лента вензелей вдоль всей страницы
  и разделители между блоками
- фон не плоская заливка: тёплые световые пятна сверху донизу и бумажное зерно
  (слой прибит к экрану, а не к странице, чтобы не тормозить прокрутку)
- кнопка музыки сверху справа: золотая пластинка, крутится пока играет
- тонкая золотая полоса прогресса прокрутки сверху

## Музыка

**Ваш трек уже внутри файла.** Отдельно ничего класть не нужно —
музыка едет вместе с `index.html`: хоть в WhatsApp, хоть на флешке, хоть
без интернета.

Трек 23 секунды и играет по кругу. Стык петли **сшит кроссфейдом**: конец
плавно перетекает в начало, поэтому щелчка на повторе не слышно.

Громкость — 50 %. Меняется в файле: найдите `VOL = 0.5` и поставьте своё
число от 0 до 1.

Заменить трек можно и без меня: положите рядом с `index.html` файл с именем
`music` — `.mp3`, `.m4a`, `.mp4`, `.ogg` или `.wav`. Сайт сначала ищет внешний
файл и только потом берёт зашитый.

> Осторожно с именем: Windows по умолчанию **прячет расширения**. Если файл
> уже `music.mp3`, а вы переименуете его в «music.mp3», на диске получится
> `music.mp3.mp3` — и сайт его не найдёт. Включите «Расширения имён файлов»
> во вкладке «Вид» проводника, чтобы видеть настоящее имя.

Музыка стартует сама в момент открытия конверта — это разрешённое действие
пользователя, поэтому браузер её пропускает. Громкость нарастает за полторы секунды.

## Как выложить в интернет

**Netlify Drop** (netlify.com/drop) — перетащить `index.html` в окно браузера,
ссылка выдаётся через 20 секунд. Самый быстрый путь.

**GitHub Pages** — залить `index.html` **в корень** репозитория (не в папку),
Settings → Pages → ветка `main`, папка `/ (root)`. Репозиторий должен быть публичным.

Заливать нужен только `index.html` — акварели и музыка уже внутри него.

## Автоскролл

Включилась музыка — через полторы секунды страница **едет сама**, сверху донизу
примерно за две минуты. Скорость подбирается под высоту страницы, так что от
количества фотографий в карусели время проезда почти не меняется.

- **тронули страницу сами** — пальцем, колесом или клавишей — автоскролл
  замирает ровно там, где стоит, без доезда по инерции
- **поставили музыку на паузу** — автоскролл тоже встаёт
- **включили музыку снова** — поехал дальше с того же места
- доехали до низа — останавливается сам

Прокрутка при этом плавная и руками: и колесо, и автоскролл крутит один движок —
позиция догоняет цель по экспоненте, поэтому и разгон, и остановка мягкие, без
рывков. На телефоне колесо не перехватывается, там родная инерция системы — она
лучше любой самодельной.

При системной настройке «уменьшить анимацию» автоскролл и перехват колеса
выключаются целиком.
